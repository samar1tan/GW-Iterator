## Model-free quality gate

Use independently authored corpora and expected source/range sets, not strings chosen after observing results. Capture worker/native coordinator/connected coordinator prompts and tool replies.

- Relevant material beyond the first four documents survives irrelevant-source reordering.
- Evidence beyond every former prefix cap is selected with correct lines and heading context.
- CJK, normalized forms, code identifiers and paths exercise the declared tokenizer. A no-overlap cross-language query exposes uncertainty and can be refined through a normal scoped lookup.
- Complete required guidance survives a reference-heavy corpus; unavailable/oversized guidance blocks before paid dispatch.
- Duplicates retain aliases; conflicts, missing/error/proposed/archived entries and role applicability have explicit handling. Project/basis isolation is tested adversarially.
- Guidance, evidence and upstream results share a finite documented input envelope. No silent head cut replaces a needed range.
- New-work capture, source/configuration races, cancellation, restart and explicit refresh preserve the correct immutable basis.
- Positioned read rejects mismatched entry/hash/revision and cannot access a live path or another corpus.
- Feedback, proposal review, archive and template updates never rewrite prior work or silently grant capability.

Template cases include new/legacy provenance, explicit empty/unknown/overridden values, v1→v2 updates, sticky choices, independent stage edits, changed/deleted-stage conflicts, missing mappings, retirement, stale preview, duplicate Apply and successful Apply followed by failed observation.

## No-model performance gate

Construct approximately 38 synthetic historical runs / 6 MB with no active model work. Measure 0/1/4 observation clients and retained hidden views. Record session/overview/workspace/detail latency, event-loop delay, decoded row/list counts and CPU where available. Compare the same harness before/after; retain workload and runtime version privately. No fixed-count speed claim is made before measurement.

Mutations, fresh account data, Stop, exact external state and confirmed receipts must remain timely. A cache hit cannot certify a fresh observation. Run affected concurrency/recovery regressions after optimization.

## Bounded live pilot

Use two small independently authored local tasks with the same input commit, available documents, effective model/effort, execution boundary and shared external acceptance checks. Compare a direct Codex route with GWI; separately identify known-pipeline and general-entry overhead when exercised. Preserve actual artifacts and failed attempts.

The pilot has at most 12 provider dispatches total, including retries and cancellation/recovery work, and at most 300 seconds per ordinary action unless its existing smaller bound applies. Do not extend that envelope automatically. Account exhaustion stops paid dispatch. Record any necessary scope change rather than increasing a quota to manufacture success.

Record useful output/quality, provider-reported input/cache/output, dispatch count, model-active/wait time, interventions and actual delivery. Shared account changes are not exact per-task charges. Exercise actual provider termination confirmation and targeted continuation where supported. Natural capacity failures remain a separate live mode; controlled faults cannot stand in for them.

## Delivery gate

Independently review actual artifacts and ordinary GUI operation in English/Simplified Chinese at desktop/narrow widths. Keep private project configuration, corpora, transcripts and captures local. Publish only original reviewed source and independently authored synthetic tests. Update PRD/UED/API/operating guidance, issue status, README/website claims and the project's indexed knowledge together. Separate implemented, model-free tested, live verified and unpassed cases in the final report.

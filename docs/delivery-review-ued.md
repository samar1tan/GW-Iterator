# Delivery review

The waiting inspector opens with the result to review, followed by independent findings, concrete source changes, previews and publication observations. Keep original stage instructions available without making users reconstruct evidence from a technical timeline.

Show a source timestamp/revision and name the producing stage and attempt. Separate actual observations from upstream reports and missing material. Images come from retained authorized browser evidence; show a clear unavailable state if a file is gone. Publication links identify their source and verified head when available, without interpreting a supplied link as passing CI.

Accept delivery and Request changes appear beside this material. Accept does not require rewriting an agent's result or manually re-entering its artifact list. A change request requires a useful finding. Generic external manual-result entry remains available as a secondary action.

Prepare review material is an explicit action with optional instructions. While its linked execution runs, show that execution and Stop/open controls rather than another preparation button or fictional progress. Finished material is inspectable before a human decision; old or stale material retains its source and is not presented as current. Preserve drafts and acknowledged receipts through refresh failures. Both project and global entry points use this same surface.

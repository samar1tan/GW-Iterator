FROM PROJECT TO DELIVERED WORK

Use the workbench.
Adjust the process when it matters.

01Start with the outcome
Describe the work or select a reusable pipeline. State the concrete result before execution starts.
02Follow work across roles
Inspect stages, handoffs, changes and checks. People and agents use the same recorded work.
03Continue with context
Keep completed work and earlier attempts. A retry uses the remaining allowance; a higher ceiling needs an explicit decision.
04Keep the useful knowledge
Connect selected project documents and reviewed lessons. Pipeline and role revisions remain inspectable.

ON YOUR MACHINE

Run GW-Iterator locally

GWI connects a local web interface to Multica and your authenticated Codex installation. It does not require a hosted GWI account.

Node.js 24–26 · Git · curl · Docker Compose · Codex
GitHub operations also require an authenticated gh CLI.

Native execution is verified on macOS. Other hosts must pass the setup checks.

Prerequisites and setup checks →
Terminal
git clone https://github.com/samar1tan/GW-Iterator.git
cd GW-Iterator
npm ci --ignore-scripts
node scripts/setup-multica.mjs
npm run build
npm start
